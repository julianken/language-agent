# src/sidecars/zh

The Chinese (Traditional) verification sidecar v0 — **deterministic legs
only** (issue #19; `docs/decisions/language-module-architecture.md` →
"Amendment — dual-instance walking skeleton", Decision 1). Python + FastAPI,
deliberately **outside** the pnpm workspace globs.

It implements the shared contract `src/packages/contract/sidecar/openapi.yaml`
— the routes type against `generated/models.py` (regenerated by
`scripts/generate-sidecar-models.sh`, freshness-gated in CI; the
implementation types AGAINST the contract, it never emits it). CI also runs
Schemathesis against the built image from the UNCHANGED shared document (the
cross-consumer proof that no ar-specific shape entered it).

## The legs (issue #19 order — every failure path fail-closed)

| # | Leg | legId / evidence id | Failure behavior |
|---|---|---|---|
| a | Closed-world exact-cover segmentation | `seed-closed-world` | no cover / out-of-world → token RED; **>1 valid cover → regenerate** |
| b | CC-CEDICT(Traditional)+Unihan `kMandarin` citation-membership re-check (variant→MOE + NFC; citation layer ONLY, never surface) | `cedict-unihan-membership` | miss → token RED (the deterministic floor) |
| c | C3 context-pinned head-set lookup — `(char, role-context) → reading` over the C9-style enumeration; two hard-coded patterns regardless: V+不/得+了 potential infix; ordinal/date 一 only via an enumerated rule | `headset-context-pinned` | unenumerated context / hard pattern → regenerate |
| d | Rule-based sandhi/不-一 resolver + conservative third-tone grouping (shifts applied only where the enumeration marks them applicable; 3+-third-tone runs across words → regenerate; within-word runs display only with a curated grouping) | `sandhi-resolver` | cross-word 3+ run, uncurated within-word run, inconsistent enumeration → regenerate |
| e | jieba voter, boundaries normalized to the pinned AS/CKIP standard before agreement is scored | `segmenter-vote` | post-normalization disagreement → YELLOW; disagreement ∩ sandhi span → regenerate |
| f | 兩/二 numeral rule (兩 before measure words; 二 for digits/ordinals) | `numeral-rule` | violation → regenerate |
| g | Intent cross-check: intent↔sense **bidirectional** coverage (v0 relation: `intent.id == tuple.senseId`; structural tokens exempt; the unrealized-intent half is skipped when a RED token is present — the withheld span may have realized it) | `intent-cross-check` (evidence only — not a declared capability leg; the capabilities AC pins the six-string list) | mismatch → **candidate-level** regenerate |

**Regenerate on the wire:** the band vocabulary is closed (GREEN/YELLOW/RED)
and `VerifyResponse` has no top-level verdict field by design, so a
candidate-level failure collapses the stream to ONE RED token of kind
`candidate` spanning the whole input, with
`annotations.payload = {action: "regenerate-candidate", reason, legId}` —
RED already means "refused; repair engine-side" (design §6.5), and for an
ambiguous cover this is literally true: the gate refuses to mint boundaries.

**C3 (committed definition, issue #19 step 2(a)):** {的, 了, 不, 一} plus
嗎/呢, admitted as pinned singles. Distinct from the full §6.8 hand-pinned
head set (的/地/得, 了, 不, 一, 行, 重, 著, 和) — NOT implemented in v0.
Since #20, every single resolves over the real curated C9 enumeration
(267 role-licensed contexts); anything outside it regenerates (fail-closed).

## Excluded by construction

`torch`, `transformers`, `g2pW`, `g2pM`/`g2pC`, `HanLP`, `OpenCC`, `pkuseg`
never ship in this image — an appearance is a **regression**, not a judgment
call (Decision 1: the full gate — g2pW, AS-configured HanLP, the refutation
jury — runs at curation time only, in the curation-toolchain container at
`curation/`, which is `.dockerignore`d out of this image's build context and
never deployed). Enforced twice: `scripts/assert-deterministic-only.sh`
(built image, CI) and `tests/test_no_neural_deps.py` (dependency environment).

## Data

- `data/cedict-extract.json` — REAL CC-CEDICT (MDBG) subset, **CC BY-SA 4.0**
  — attribution in `data/NOTICE.md`, shipped in the image.
- `data/unihan-kmandarin.json` — REAL Unihan `kMandarin` subset (© Unicode,
  Inc., Unicode Terms of Use). Both extracts are as small as the closed world
  allows; regenerate with `scripts/extract_membership.py` when the closed
  world grows.
- `data/lexicon.json` — BUILD-GENERATED from `src/packages/lang-zh/assets/`
  by `scripts/build_lexicon.py`; never hand-edited. CI freshness gate:
  regenerate + `git diff --exit-code`. Generated from the **#20 curated
  sliver** (58 words + 267 C9 contexts; `provenance: curated — machine gate
  complete; native gold pass pending (#20 AC7)`) — the curation pipeline,
  its recorded gate results, and the g2pW drift baseline live in
  `curation/` (see its README).

## Annotations

Tokens carry `annotations: {lang: "zh", schemaId: "zh-annotations/v1",
payload}`. Payloads: words → `{readingId, citationPinyin[], surfacePinyin[]
(tone marks, display-ready), pos, senseId, gloss}`; singles →
`{citationPinyin[], surfacePinyin[], contextKey, rule?}`; RED → `{reason}`;
regenerate → `{action, reason, legId}`. The zod/JSON-Schema formalization of
`zh-annotations/v1` lands with `@la/lang-zh` (#21), which owns the schema id.

## Endpoints

- `GET /healthz` — liveness from the HTTP layer alone; never touches a table.
- `GET /readyz` — honest readiness: 200 only after ALL tables (sliver
  lexicon, CC-CEDICT, Unihan, C9 context table) + the jieba voter are loaded.
  Warmup is **seconds-scale** (measured ~1.2–1.3 s container start → first
  200; no model load) — sizes #11's startup-probe window.
- `GET /v1/capabilities` — exactly
  `['cedict-unihan-membership','seed-closed-world','headset-context-pinned','sandhi-resolver','segmenter-vote','numeral-rule']`,
  `language: zh`, `contractVersion` mirroring the spec's `info.version`.
- `POST /v1/verify` — the gate (text-in, banded tokens-out).

## Commands

```sh
# tests (unit + golden HTTP fixtures, incl. the fail-closed negative paths)
cd src/sidecars/zh
uv venv .venv -p 3.12
uv pip install --python .venv/bin/python -r requirements.txt -r requirements-dev.txt
.venv/bin/python -m pytest -q

# regenerate the Pydantic models from the shared spec (CI freshness-gated)
pnpm run spec:generate:python

# rebuild the baked lexicon from @la/lang-zh/assets (CI freshness-gated)
python3 src/sidecars/zh/scripts/build_lexicon.py

# image: build, torch-free gate, measure (size / cold-start / RSS)
docker build -t language-agent/sidecar-zh:dev src/sidecars/zh
bash src/sidecars/zh/scripts/assert-deterministic-only.sh language-agent/sidecar-zh:dev
bash src/sidecars/zh/scripts/measure.sh language-agent/sidecar-zh:dev

# conformance against the UNCHANGED shared spec (container on :8137)
uvx schemathesis@4.22.3 run src/packages/contract/sidecar/openapi.yaml \
  --url http://127.0.0.1:8137 --checks all
```

Measured numbers (size, cold-start, RSS) live in
`docs/decisions/hosting-walking-skeleton.md` → the zh row.
