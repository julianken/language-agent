# Instructions for reviewers (Traditional Chinese vocabulary check)

*(Audience: bilingual native Mandarin speakers, Traditional-script literate.
Written in English so the screening requirement — you can read English task
instructions — doubles as the communication channel; the ITEMS are all in
Chinese.)*

Thank you for helping check a beginner Traditional-Chinese vocabulary set
(Taiwan usage). You will see ~340 short items. Each item is one of:

1. **A word** — a Traditional Chinese word with its Hanyu Pinyin reading and
   a short English gloss.
   *Example: `茶 — chá — "tea"`*
2. **A function-word-in-context item** — one highlighted character (的, 了,
   不, 一, 嗎, or 呢) inside a short sentence, with the pinyin reading we
   claim it has **in exactly that sentence** (tone changes like bù→bú and
   yī→yí/yì are written as pronounced).
   *Example: `他[不]是老師。 — claimed reading of 不 here: bú`*
3. **A full sentence** — a short sentence with its word segmentation and full
   pinyin. Judge whether the sentence is natural, grammatical Taiwan
   Mandarin and whether every reading is right.

## Your verdict, per item

- Choose **是** if the item is correct as claimed.
- Choose **否** if ANYTHING is wrong — wrong character, wrong reading or
  tone **for that context**, unnatural/ungrammatical sentence, misleading
  gloss — and write what's wrong (and the correct form if you can) in the
  **correction** box. A short note is fine (e.g. `期 should be qí in
  Taiwan`, `了 here is liǎo not le`, `nobody says this sentence`).

## Judging guidelines

- **Taiwan usage is the standard.** If a reading is Mainland-standard but
  wrong for Taiwan (or vice versa), say so in the correction box — choose 否
  only if the claimed reading would be wrong *in Taiwan*.
- **Neutral tones:** several words are shown with dictionary citation tones
  (e.g. 學生 xuéshēng vs. colloquial xuésheng). Treat citation-vs-colloquial
  neutral tone as CORRECT (是), but feel free to note it.
- **Segmentation:** the set deliberately splits some units finer than daily
  intuition — 星期|一, 喝|茶, 不|要, 一|個 are **conventions, not errors**.
  Only mark 否 if a split crosses a real word wrongly (e.g. cutting 老師
  into 老|師 would be wrong).
- **Simple ≠ wrong.** These are deliberately simple beginner sentences.
  Ellipsis that a native speaker would accept in conversation (e.g.
  「我買一個。」) is fine.
- Work at your own pace; accuracy matters more than speed. Some items have
  known answers planted as quality checks — careless straight-lining will be
  detected and the submission rejected per the study terms.

## Format

The task sheet has one row per item: `row_id`, `item` (the Chinese content +
claim, as above), `verdict` (是/否), `correction` (free text, required when
否). Please answer every row.
