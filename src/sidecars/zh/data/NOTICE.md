# Third-party data notices (zh verification sidecar)

This directory (and the built sidecar image, which copies it verbatim) bakes
in subset extracts of two third-party data sources. This notice ships
alongside the data per `docs/plans/chinese-instance-design.md` §10.3
(CC BY-SA quarantine + notice).

  extract remains under CC BY-SA 4.0; the source dump's `#!` metadata header
  is preserved inside the extract for provenance.

## What is NOT here

The sliver lexicon (`lexicon.json`) is build-generated from
`src/packages/lang-zh/assets/` (currently the #19 curation stub, marked
`provenance: stub — replaced wholesale by #20`) — first-party data, no notice
required. jieba's bundled dictionary and pypinyin's data ship inside their
respective MIT-licensed PyPI packages, not in this directory.
